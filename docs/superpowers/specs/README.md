# Specs Source Of Truth

This directory is the source of truth for active product requirements, architecture decisions, and scope.

## Rules

- New product decisions belong here, not in `docs/plans/` or `docs/superpowers/plans/`
- If a brainstorm or implementation plan disagrees with a spec here, the spec wins
- Old planning docs should be reduced to archival pointers instead of carrying live requirements
- `docs/tivana/` is reference documentation for the runtime/protocol, not the place for Atlas product direction

## Canonical Active Specs

- `2026-03-28-tivana-atlas-design.md` — Atlas MVP requirements and architecture
- `2026-03-29-tivana-reference.md` — Tivana runtime, protocol, SDK, and development reference

## Reference Boundary

- Everything still active should live in this directory
