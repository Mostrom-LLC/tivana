# 1. Accessibility Auditing (ADA/WCAG)
Agent audits pages for accessibility compliance with full visual context.

### What the agent detects:
- Color contrast failures (calculates WCAG ratios from actual colors)
- Missing accessible names on interactive elements
- Touch targets below 44x44px minimum
- Missing or invisible focus indicators
- Broken heading hierarchy (h1 → h3 skip)
- Images without alt text
- Keyboard navigation issues
### Why this matters:
Existing tools (axe, Lighthouse) run static checks. This agent sees computed styles — the actual rendered colors, sizes, and focus states. It catches issues that static analysis misses.


---

# 2. Visual Regression Testing
Agent notices when something looks wrong — not just when it breaks.

### What the agent catches:
- Button changed from green to blue (color shift)
- Text is now truncated or overflowing
- Element is misaligned by a few pixels
- Font weight changed (bold → normal)
- Spacing is inconsistent between elements
- Border radius changed
### Why this matters:
Screenshot diffing tools flag pixel changes but dont understand them. This agent knows a button changed color — it can reason about whether thats intentional or a bug.


---

# 3. Exploratory QA
Agent explores like a human tester — clicks around, notices anomalies, finds edge cases.

### What the agent does:
- Explores pages without a script
- Tries unexpected inputs (empty, long strings, special chars)
- Notices error states and broken layouts
- Finds flows that feel off even if they work
- Reports what it found in natural language
### Why this matters:
Scripted tests only check what you tell them. Exploratory testing finds the bugs you didnt think to look for.


---

# 4. Design System Validation
Agent verifies that UI matches the design system spec.

### What the agent checks:
- Colors match design tokens (#238636 not #22863a)
- Typography uses correct font/size/weight
- Spacing follows 8px grid
- Border radius is consistent (6px everywhere)
- Components match Figma specs

---

# 5. User Flow Testing
Agent completes real user journeys and reports on the experience.

- Sign up flow — confusing? too many steps?
- Checkout flow — errors clear? progress visible?
- Search experience — results relevant? filters work?
- Mobile responsiveness — does it work on small screens?

---

# 6. Competitive Analysis
Agent browses competitor sites and reports on UX patterns, features, and design choices.

- How does competitor X handle onboarding?
- What pricing tiers do they show?
- How many clicks to reach checkout?
- What UI patterns do they use?

---

# 7. Continuous Monitoring
Agent watches production sites and alerts when something changes or breaks.

- Critical user flow stopped working
- Page layout broke on deploy
- Third-party widget disappeared
- Performance degraded (page takes too long to become interactive)
